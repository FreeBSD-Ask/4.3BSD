# 4.3BSD UNIX 操作系统的设计与实现

《4.3BSD UNIX 操作系统的设计与实现》（*The Design and Implementation of the 4.3BSD UNIX Operating System*）简体中文翻译项目，由 FreeBSD 中文社区译制，基于 GitBook 格式发布。

## 关于本书

* 原书：*The Design and Implementation of the 4.3BSD UNIX Operating System*
* 作者：Samuel J. Leffler、Marshall Kirk McKusick、Michael J. Karels、John S. Quarterman
* 出版：Addison-Wesley，1989 年
* 篇幅：5 个部分共 13 章，另有词汇表与索引，中文章号与原书 1:1 对应

本书是关于 Berkeley UNIX（BSD）内核设计与实现的权威著作：从 UNIX 历史与设计目标讲起，依次剖析内核服务、进程管理与内存管理、I/O 系统（描述符、文件系统、设备驱动、终端处理）、进程间通信与网络协议栈，最后以系统启动流程收尾。书中对 4.3BSD 内核数据结构、算法与权衡取舍的论述，是后续《4.4BSD 操作系统的设计与实现》一书的直接前身。
