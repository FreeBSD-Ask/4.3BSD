# 契约：en/ 视觉转录格式

**用途**: 约束子代理从页面 PNG 转录英文原文的输出格式。`en/` 是翻译的唯一英文底稿来源；OCR 文本层禁止进入本产物。

## 文件与编码

- 路径：`en/NN-chXX-<slug>.txt`，UTF-8，LF。
- `NN` 为提取序号（01 前言、02 第 1 章 …… 14 第 13 章、15 词汇表、16 索引底稿）。

## 标记语法（行首独占）

| 标记 | 含义 |
| ---- | ---- |
| `[[PAGE 123]]` | 印刷页 123 从此处开始；每页一个，页码单调递增 |
| `[FIGURE p.123 图 4.2 …图注全文]` | 该处有一幅插图：页码 + 图注原文；插图本体另行导出到 `.gitbook/assets/` |
| `[TABLE p.123 N rows × M cols 标题或首行]` | 表格：页码 + 规模 + 表题/表头 |
| `[CODE p.123 C]` | 代码清单开始：页码 + 语言（C/asm/sh/…）；代码本体逐字符照录直到 `[CODE END]` |
| `[CODE END]` | 代码清单结束 |
| `[FOOTNOTE p.123] …` | 脚注内容 |
| `[UNCLEAR p.123 无法辨认说明]` | 视觉存疑点：宁可标记不得臆测 |

## 转录规则

1. 以页面图像为唯一依据；不参考、不复制 PDF 文本层内容。
2. 保留原书段落划分；连字符断词重组（如 `previ-\nously` → `previously`）。
3. 代码、命令、标识符、数字逐字符照录；存疑字符用 `[UNCLEAR]` 行内标记（如 `si[UNCLEAR]e`）并在该页标记行说明。
4. 页眉（书名/章名）、页脚页码不转录；正文中的页内交叉引用（see page N）原样保留。
5. 双栏页（参考文献、词汇表、索引）先左栏后右栏，逐栏转录。
6. 习题（Exercises）与参考文献（References）完整转录，题号/文献编号保持。
7. 每完成一章，子代理向主会话回报：起止页、`[FIGURE]`/`[TABLE]`/`[CODE]` 清单、`[UNCLEAR]` 总数；不回传全文。

## 验收

- 每页恰一个 `[[PAGE n]]` 且单调递增。
- `[UNCLEAR]` 总数为 0，或每条都有主会话的人工裁决注记。
- 抽 3 页与 PNG 逐词比对一致（含标点与脚注）。
