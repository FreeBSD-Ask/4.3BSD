# 契约：进度与日志文件

## PROJECT-PROGRESS.md（会话接手必读）

顶部固定三段（最新在上）：

```markdown
# 当前任务
<正在做的单元与轮次>

# 下一步
<下一个具体动作>

# 轮次记录
| 单元 | 初译 | 校对一 | 校对二 | 校对三 | 复查 | 备注 |
| ---- | ---- | ------ | ------ | ------ | ---- | ---- |
```

* 每完成一轮、每次提交、每次阻塞或方案变更、每次会话结束都必须更新。
* 未执行的轮次不得勾选；复查找出新问题时该单元回到"校对中"并重新计数。

## CHANGELOG.md（里程碑日志）

* 条目式：`- 2026-10-24 翻译第 1 章（初译完成）`。
* 只记里程碑（整章初译/整章三轮校对/词汇表完成/索引完成），单节细流看 git log。

## 提交信息

* 中文一行，如"翻译第 6 章 I/O 系统概述""术语表新增 40 条"。
* 只提交相关 `.md`/脚本；`.gitbook/assets/` 改动单独提交并注明；`en/`、`script/`、PDF 不入库。
