# Phase 1 Data Model: 实体与校验规则

对应 spec.md Key Entities；全部实体以仓库文件形态存在，无运行时存储。

## 1. 术语条目（Terminology Entry）

- **载体**: `yi-zhe-shuo-ming.md` 表格行。
- **字段**: 英文原词（唯一键，区分大小写）｜义项（可选，区分 block=块/阻塞等多义词）｜中文译名（每义项唯一）｜备注（来源/查证链接/保留英文的理由）。
- **校验**: 同一英文原词 + 同一义项不得出现两个中文译名；中文译名一经用于正文不得再改名（改名需全书同步替换并记录）；人名条目中文列必须为"—"（不译）或"保留英文"。

## 2. 章节页面（Chapter Page）

- **载体**: 仓库根各分部目录下的 `X.-slug.md` / `X.Y.-slug.md`。
- **字段**: 文件名（`X.`/`X.Y.` 前缀 + 拼音 slug，无空格/中文/英文冒号）；H1（与 `SUMMARY.md` 对应条目逐字一致）；层级（章首页=H1，节内 `X.Y.Z`=H2，`X.Y.Z.W`=H3）；所属分部（由目录路径决定）。
- **校验**: H1 一致性由 sync-headers CI 兜底；标题层级不得跳级（MD001）；页面非空且覆盖 `en/` 对应区段的全部正文元素（段落/图/表/习题/参考文献）。

## 3. SUMMARY 条目（TOC Entry）

- **载体**: `SUMMARY.md`。
- **字段**: 分部条目（`## 第N部分 名称`，纯标题不链接）；章/节条目（`* [标题](路径)`，标题=目标页 H1）。
- **校验**: 首行恒为 `# Table of contents`；每个链接路径指向存在的文件（file-name-check CI）；条目集合与原书目录 1:1（`script/compare_structure.py` 差异为 0）。

## 4. 图片资产（Image Asset）

- **载体**: `.gitbook/assets/fig-<章>-<序号>-<slug>.png`。
- **字段**: 文件名（小写字母/数字/连字符）；来源（PDF 嵌入图像 xref + 印刷页码）；被引用集合（≥1 个 `.md`）。
- **校验**: 引用写法与磁盘文件名逐字符大小写一致；100% 被引用、100% 可解析（check-images CI）；不使用外链。

## 5. en/ 原文文件（Transcribed Source Text）

- **载体**: `en/NN-chXX-<slug>.txt`（不入库）。
- **字段**: 章号；起止印刷页码；正文（视觉转录）；标记（`[[PAGE n]]`、`[FIGURE p.n ...]`、`[TABLE p.n ...]`、`[UNCLEAR ...]`）。
- **校验**: 每页恰有一个 `[[PAGE n]]` 标记且页码单调递增；`[UNCLEAR]` 计数为 0（或已附人工裁决注记）方可作为翻译底稿；与页面图像抽样比对一致。

## 6. 索引词条（Index Entry）

- **载体**: `fu-lu/shu-yu-suo-yin.md` 列表项。
- **字段**: 中文术语；英文原词（括注）；拼音排序键；链接集合（≥1 个指向存在页面的相对路径）。
- **校验**: 全部链接可解析（links CI）；按拼音排序无乱序段；同一中文术语不重复成条（多指向合并为一个词条）。

## 7. 进度记录（Progress Record）

- **载体**: `PROJECT-PROGRESS.md`（当前状态）+ `CHANGELOG.md`（里程碑日志）。
- **字段**: 单元（章/节）；轮次（初译/校对一/校对二/校对三/复查）；完成日期；遗留问题；下一步。
- **校验**: 未执行的轮次不得勾选；每条记录与 git 提交历史可对账；每轮/每次会话结束时必须更新（AGENTS.md 强制）。

## 状态流转（仅术语条目与进度记录存在状态）

- 术语条目: `待议（保留英文）` → `已定（唯一译名）`；不允许 `已定 → 已定（改名）` 除非全书同步替换完成。
- 进度记录: `未开始` → `初译中` → `校对中（1→2→3）` → `复查中` → `完成`；复查发现问题则回到 `校对中` 重入下一轮（递归工作流）。
